# EchoEarth

**Rivers, lakes, and forests speak — in their own voice, grounded in real data.**

EchoEarth is an environmental awareness platform that gives 15 bodies of water a first-person voice powered by live environmental metrics. Users can explore locations across three eras (1976 · Today · 2050), hear AI-narrated stories grounded in real sensor data, and write letters to the places they love — which write back.

Built for the **NextStep Hacks 2026 — Earth Forward** hackathon.

---

## What it does

| Feature | Description |
|---|---|
| **AI Narration** | Each location speaks in first person, generated by Groq (Qwen) using live temperature, air quality, and derived dissolved oxygen data |
| **Live Data** | Temperature and AQI pulled in real time from Open-Meteo (free, no key). Dissolved oxygen derived via the Benson–Krause equation from live temperature + PM2.5 |
| **Three eras** | Toggle between 1976 (historical reference), Today (live data), and 2050 (IPCC scenario projection) |
| **Interactive map** | Leaflet map with color-coded health pins for all 15 locations worldwide |
| **Letters** | Write a letter to a river — it replies in character, citing its own real metrics via streaming AI |
| **Journal** | Save location snapshots for later comparison |
| **ElevenLabs TTS** | The river narration is read aloud by a culturally-assigned voice |
| **Take Action** | Every narration ends with 3 specific, concrete asks from the river to the reader |

## Tech stack

- **Next.js 16** (App Router) — framework
- **Groq API** (Qwen 3 model) — streaming AI narration + letter replies
- **ElevenLabs API** — text-to-speech with culturally-assigned voices
- **Open-Meteo** — free real-time weather + air quality (no key required)
- **USGS Water Services** — live stream discharge for US rivers (no key)
- **Leaflet** — interactive map
- **Framer Motion** — animations
- **Tailwind CSS v4** — styling
- **@vercel/og** — dynamic OG preview images

## Running locally

### Prerequisites

- Node.js 20+
- npm

### 1. Clone and install

```bash
git clone https://github.com/your-username/eco-earth.git
cd eco-earth
npm install
```

### 2. Set environment variables

Create a `.env.local` file:

```env
GROQ_API_KEY=your_groq_api_key_here
ELEVENLABS_API_KEY=your_elevenlabs_api_key_here
```

**Getting free API keys:**
- **Groq:** Free at [console.groq.com](https://console.groq.com) — generous free tier
- **ElevenLabs:** Free tier at [elevenlabs.io](https://elevenlabs.io) — 10,000 chars/month

> The app works without ElevenLabs (TTS is disabled gracefully). Open-Meteo and USGS require no key.

### 3. Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Design principles

1. Every metric shown has a named source and a timestamp.
2. Projected values are always labelled as scenarios, not forecasts.
3. The voice of the place is poetic but never factually misleading.
4. No data is invented. If a number is uncertain, we say so.
5. This project is not affiliated with any government body or lobby.
